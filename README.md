# ЗОНА / COUNTDOWN

Личный шуточный таймер блокировки в VALORANT. React, TypeScript, Vite и Tailwind CSS v4. Без backend, базы данных, внешних шрифтов и сетевых запросов таймера.

## Разработка и проверки

Используйте Node.js 22.12+ или 24+.

- `npm ci` — установка зависимостей из lock-файла.
- `npm run dev` — локальная разработка.
- `npm run lint` — ESLint.
- `npm test` — проверки обратного отсчёта и прогресса, включая граничные значения.
- `npm run build` — строгая проверка TypeScript и production-сборка.
- `npm run preview` — локальный просмотр production-сборки.

## Даты

Конфигурация: `src/config/countdown.ts`.

- Начало: `2026-10-12T00:00:00+05:00`.
- Окончание: `2027-01-10T00:00:00+05:00`.
- Часовой пояс отображения: `Asia/Tashkent`.

Обе даты содержат явное смещение UTC+05:00 и не зависят от часового пояса устройства. При изменении дат сохраняйте явное смещение и согласованный `timeZone`. Начало должно быть раньше окончания. Тесты конфигурации фиксируют текущие согласованные даты; при намеренном изменении дат обновите соответствующие проверки.

Таймер пересчитывает остаток по системным часам каждую секунду и сразу после возвращения во вкладку. В скрытой вкладке интервал приостанавливается. После перезагрузки состояние вычисляется заново. При завершении остаток равен нулю, отображается состояние освобождения, прогресс равен 100.00%. До окончания процент не округляется вверх до 100.00%. Если `startsAt` равен `null`, процент до окончания не вычисляется.

Точность зависит от часов устройства. Таймер показывает наступление настроенной даты и не проверяет фактический статус игрового аккаунта.

## Структура

- `src/config` — даты и часовой пояс.
- `src/lib` — расчёты остатка, прогресса и форматирование процента.
- `src/hooks/useCountdown.ts` — интервал, синхронизация видимости и очистка обработчиков.
- `src/components` — компоненты интерфейса и их локальные стили.
- `src/index.css` — Tailwind и базовые стили.
- `src/App.css` — общие стили и адаптивность.
- `tests` — тесты на встроенном Node.js test runner.

## Публикация

После успешных проверок разместите содержимое `dist/` на статическом хостинге. Сборка рассчитана на корень домена; при размещении в подпапке задайте соответствующий `base` в `vite.config.ts` и соберите проект заново.

`node_modules`, `dist`, локальный кэш и метаданные сборки исключены через `.gitignore`. Неподключённые ресурсы стартового шаблона удалены. Favicon — `public/favicon.svg`: красный геометрический знак на чёрной подложке со срезанными углами. Подключён в `index.html` с учётом `base` и копируется в `dist/` при сборке.

Перед публикацией вручную оцените плавность анимаций и читаемость на реальных устройствах и в целевых браузерах. Все анимации отключаются при `prefers-reduced-motion: reduce`.
