# ЗОНА / COUNTDOWN

Сайт-отсчёт до конца блокировки в VALORANT. Три месяца строгого режима, личное дело заключённого, прошение на УДО и железный отказ. Сделан для друзей и ради удовольствия, всерьёз его воспринимать не нужно.

---

## Что внутри

- **Обратный отсчёт** до 10 января 2027, 00:00 по Ташкенту: дни, часы, минуты, секунды. Дата задана с явным часовым поясом, поэтому у всех посетителей показывает одно и то же. Когда время выходит, сайт переключается на «СВОБОДА».
- **Шкала срока** с процентом отбытого наказания (срок идёт с 12 октября 2026).
- **3D-карточка с датой освобождения.** Наведи курсор (или тапни на телефоне), и она перевернётся с предложением подать прошение на УДО. Нажмёшь кнопку, и тебе вежливо откажут. Работает и с клавиатуры: Enter, Escape.
- **Материалы дела:** профиль заключённого и девять эпизодов-обвинений, которые раскрываются по клику.
- **Мировое время:** аналоговые и цифровые часы Ташкента и Лондона. Переход Лондона на летнее и зимнее время учитывается автоматически.

## Запуск

Нужен Node.js 22.6 или новее.

```bash
npm install
npm run dev        # запустить локально
npm run typecheck  # проверка типов
npm run lint       # ESLint
npm test           # тесты
npm run build      # production-сборка в dist/
npm run preview    # посмотреть собранный сайт
```

Типы, линтер, тесты и сборка также проверяются в GitHub Actions при каждом push в `main` и в pull request.

## Как поменять дату

Всё лежит в [`src/config/countdown.ts`](src/config/countdown.ts): начало срока, конец срока и часовой пояс. Даты пишите с явным смещением, например `2027-01-10T00:00:00+05:00`.

Тексты вроде «Три месяца» и «90 суток» написаны руками прямо в компонентах, так что при смене срока поправьте и их. Список эпизодов дела живёт в [`src/config/caseFiles.ts`](src/config/caseFiles.ts).
